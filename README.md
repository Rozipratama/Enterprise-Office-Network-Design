# Enterprise Office Network Design

## Project Overview

This project demonstrates the design and simulation of an enterprise office network using Cisco Packet Tracer.

The simulated office includes multiple departments, a centralized server room, wired endpoints, network printers, IP phones, and wireless access points.

## Objectives

- Design a physical office network layout.
- Build a logical network topology using routers and switches.
- Plan IPv4 addressing and departmental network segmentation.
- Configure routing and network services.
- Test connectivity and document troubleshooting results.

## Office Departments

- IT
- Human Resources (HR)
- Finance
- Marketing
- Sales
- Administration
- Server Room
- Break Room

## Technologies and Tools

- Cisco Packet Tracer
- IPv4 subnetting
- Ethernet switching
- Routing
- VLANs (planned or implemented)
- DHCP and DNS (planned or implemented)
- Wireless networking

## Repository Structure

- `topology/` — Packet Tracer simulation and logical diagrams
- `physical-design/` — Office floor plan and physical network layout
- `configs/` — Router and switch configurations
- `evidence/` — Connectivity tests and configuration screenshots
